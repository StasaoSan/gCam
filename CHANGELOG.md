# История изменений gCam

Здесь перечислены пользовательские изменения опубликованных версий. Версия APK должна
совпадать с Git-тегом: тегу `v4.7` соответствует раздел `[v4.7]` и файл
`gCam_[v4.7].apk`.

## [Unreleased]

## [v5.1] - 2026-10-17

- Новая иконка приложения с изображением камеры 360°.
- Основным местом записи стал выбранный USB-накопитель; файлы сохраняются в `Movies/gCam`.
  Запись во внутреннюю память доступна отдельно с предупреждением.
- Добавлены рекомендуемые настройки записи и предупреждение о нагрузке при четырёх
  камерах в максимальном разрешении.
- Добавлено плавающее окно с камерами поверх других приложений.
- Добавлен отдельный доступ gBlind к видеопотокам приборной панели.
- Исправлена подготовка записи при заполненном архиве: удаление старых незащищённых
  сегментов выполняется в фоне до запуска камер, с резервом 2 ГБ и без смешивания архивов USB и внутренней памяти.
- Выбор USB-накопителя теперь явно отображается в настройках; системный выбор папки не требуется.

## [v5.0] - 2026-10-14

- Просмотр четырёх камер: левой, правой, передней и задней.
- Фоновая запись выбранных камер в MP4 с настройкой качества, FPS, битрейта и длины фрагментов.
- Циклический архив с настраиваемым лимитом, просмотром, паузой и перемоткой записей.
- Отдельно включаемые отметки даты и времени, GPS и скорости на видео.
- Передача боковых камер в ANHUD для проекции и приборки, в том числе во время записи.
- Автозапуск камер и записи, индикатор состояния и диагностика видеопотоков.

## [v4.94] - 2026-10-13

- Исправлен переход от превью камер к записи: превью закрывается явно перед запуском регистратора.
- Добавлена диагностика нажатия кнопки записи и закрытия превью.

## [v4.93] - 2026-10-12

- Доступ ANHUD к камерам теперь подтверждается в gCam при разных подписях приложений;
  одинаково подписанные debug-сборки продолжают работать автоматически.
- Внешнему ANHUD доступны только HUD-команды, управление записью остаётся внутри gCam.
- Исправлено соответствие версии APK и Git-тега при выпуске.

## [v4.91] - 2026-10-12

- Обновлён GitHub Actions workflow: проверка сборки, подписанный APK и заметки релиза из changelog.
- Сборка и обновления остаются в публичном репозитории gCam; отдельный репозиторий релизов не нужен.

## [v4.8] - 2026-10-08

- Добавлена вкладка обновлений: проверка GitHub Releases, заметки версии, скачивание и запуск
  системной установки APK.
- Перед установкой проверяются SHA-256, пакет, версия и подпись скачанной сборки.
- Сборка по тегу теперь публикует подписанный APK и changelog в GitHub Release.

## [v4.7] - 2026-10-08

- Добавлен независимый автозапуск фонового моста gCam и автоматический старт записи.
- Добавлен резервный автозапуск через службу специальных возможностей для автомобильных
  прошивок, подавляющих обычный boot broadcast.
- Добавлена цветная точка состояния связи с ANHUD, получения кадров и записи; положение точки
  настраивается отдельно по X и Y.
- Расширен мост ANHUD для одновременной передачи левой и правой боковых камер, кадрирования,
  коррекции fish-eye и выбора формы окна.
- Расширена встроенная диагностика QCarCam/EGL и состояния аппаратного видеопотока.
- Добавлена автоматическая сборка APK по Git-тегу.

## [v4.6] - 2026-10-03

- Статус zero-copy и причины перехода на PBO fallback теперь показываются внутри приложения.

## [v4.5] - 2026-10-03

- Завершены диагностический и preview-контуры EGLImage, синхронизация fence и проверка четырёх
  камер.

## [v4.4] - 2026-10-03

- Добавлен защищённый Binder/AIDL-мост боковых камер для ANHUD.

## [v4.3] - 2026-10-03

- Добавлен путь записи ION → EGLImage → GLES → MediaCodec с безопасным PBO fallback.

## [v4.2] - 2026-10-03

- Добавлены настройки FPS, качества и битрейта видеорегистратора.

## [v4.1] - 2026-10-03

- Добавлены четыре одновременных preview и библиотека записей в приложении.

## [v4.0] - 2026-10-03

- Добавлен многокамерный видеорегистратор на базе прямого QCarCam/HIDL-доступа.
